## Setup Guide: Install GitHub Desktop and Create a GitHub Account 

This task prepares your system for version control and connects you to GitHub, used in all DESCARTES modules.

---

### 1. Install GitHub Desktop

GitHub Desktop includes Git and a graphical interface for version control.

* Download and install from: [https://desktop.github.com](https://desktop.github.com)
* After installing, open the app
* Log in using your GitHub account

Git is installed automatically with GitHub Desktop.

---

### 2. Create a GitHub Account

GitHub is the platform for storing and sharing your code.

* Go to [https://github.com](https://github.com)
* Register using your University of Hawai‘i email
* Enable two-factor authentication (2FA)

---

### 3. Create and Clone a Repository

A repository stores your files and tracks changes.

* On GitHub:

  * Click **New repository**
  * Name it `github-test`
  * Make it **public**
  * Check **Add a README file**
* In GitHub Desktop:

  * Go to **File > Clone repository**
  * Select `github-test` from your GitHub account
  * Choose a folder to save it locally
  * Click **Clone**

---

### 4. Make a Commit and Push

* In the cloned folder, create a file called `test.md`
  Example content:

  ```
  # GitHub Test Repo
  ```

* In GitHub Desktop:

  * You’ll see the new file listed under **Changes**
  * Type a summary message: `First test commit`
  * Click **Commit to main**
  * Click **Push origin** to upload the file to GitHub
