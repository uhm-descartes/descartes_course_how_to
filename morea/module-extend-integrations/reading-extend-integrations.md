## Integration Overview

DESCARTES MOREA modules can be extended by embedding or linking to interactive content and connecting with institutional platforms.

---

### Embedding

HTML `<iframe>` can embed:

- YouTube or Vimeo videos
- Google Forms
- H5P interactive elements
- Maps or other web-based tools

---

### Jupyter Notebooks

Convert to HTML for direct linking. Keep source `.ipynb` in repository for version control.

---

### LMS Integration

Link DESCARTES content into UH-supported LMS (Lamaku). Test authentication and access from student accounts.

---

### Documentation

Record integration details to ensure reproducibility and troubleshoot when tools change.
